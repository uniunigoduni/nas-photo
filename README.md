## 概要
NAS-PHOTOは、設定したフォルダ内の画像・GIF・動画を横断・再帰的に一覧表示し、ソートができて、キーボードショートカットで次々とメディアを見ることができ、画面分割ができる、ラズパイ上でも動くPWA対応のウェブホストのアプリです。
## 使い方
### 基本的な使い方
#### 0.起動
実行ファイルを起動し、ブラウザから確認します。デフォルトではポートは9070です。
#### 1.ログインパスワードを設定
最初はログインパスワードを設定する画面に入ります。

この画面でEnglishまたは日本語を選択できます。初期値はEnglishです。あとからでも設定で変えられます。

本アプリはローカルでのホスト前提であり、パスワード保護は簡易的なものです。外部からのアクセスはVPNを活用してください。

設定したいパスワードを二回入力し、「続行」を押して次に進みます。
#### 2.フォルダ設定
本アプリで表示したいフォルダをGUIで選びます。「フォルダを選択」を選び選択した後、選択したフォルダの下に「＋」ボタンが出てくるので、そこを押したら複数フォルダを選択できます。もちろん一つのフォルダだけを選択することもできます。

選択し終わったら「続行」を押して次に進みます。
#### 3.ログイン
ログイン画面が表示されます。2回目以降はこの画面から始まります。

設定したパスワードを入力して「続行」を押し、認証が完了したら次に進みます。
#### 4.一覧表示
初回はインデックス作成のため時間がかかります。上のプログレスバーが100%になると表示されます。2回目以降は新しく追加されたメディアの表示には同様に時間がかかりますが、前回読み込んだものは即時表示されます。

一覧表示画面では画像・GIF・動画の大きめのサムネイルが一覧表示されます。

上の「ソート」を押すと表示順を撮影日・作成日・変更日・名前、またその昇順降順で変えられます。

「表示」を押すと表示方法をリバー・正方形、大きさを小・中・大で選べます。リバー表示では画像を切り抜かずに元の縦横比を保ち、行内の高さを揃えながら右端まで自然に並べます。

「フィルター」では、「表示するメディア」（すべて・画像／GIF・動画）と「絞り込み条件」（なし・重複のみ）をそれぞれ選べます。例えば「動画」と「重複のみ」を組み合わせると、重複判定された動画だけを表示します。「重複のみ」では、ファイル内容が完全一致するメディアをグループごとに続けて表示します。サイズ・SHA-256・内容比較で判定し、再圧縮やリサイズされたファイルは完全一致には含めません。

好きなメディアをクリックで詳細表示できます。
#### 5.メディア表示
メディアが大きく表示されます。

動画は即時再生されます。

操作ボタンはマウスのホバーで表示されます。

左にある「←」ボタンで一覧表示でいう所の左のメディア、右にある「→」ボタンで右のメディアを表示します。

下にある「🔁」ボタンでループ再生を切り替えます。デフォルトはオンです。

メディアの表示領域以外をクリックするか、左上にある「×」ボタンで一覧表示に戻ります。

「×」の右にあるゴミ箱ボタンを押し、「削除しますか？」で「はい」を選ぶと、そのファイルだけを参照フォルダ内の `_nas-photo-trash` へ移します。ゴミ箱内は一覧・メディア配信・重複判定から除外されます。ファイル自体は残り、アプリから完全削除する機能はありません。容量を空ける場合はファイルマネージャーで手動削除してください。元の場所へ手動で戻したファイルは、再スキャンで再表示できます。

右上にある「＋」ボタンで右に画面が分割追加されます。右側は、現在開いているメディア、ソート・フィルター・一覧の表示設定、画像の拡大率・表示位置を引き継いだ状態で始まります。動画の再生位置は右側へ引き継がず、先頭から再生します。音量・ミュート・ループ・再生速度・一時停止状態は引き継ぎます。左側の再生位置は分割時・分割解除時に保持します。分割後は左右で別のメディアを選んで表示・再生できます。

動画再生の場合、同様にマウスのホバーで下にシークバーと再生ボタンと音量調節が表示されます。

キーボードショートカットは以下の通りです。
- qキー　左のメディア（画面１）
- wキー　右のメディア（画面１）
- aキー　左のメディア（画面２）
- sキー　右のメディア（画面２）
- eキー　画面分割の追加/解除
- lキー　ループのオンオフ（左右両方に適用）
- mキー　動画のミュートのオンオフ（左右両方に適用）
- スペースキー　動画の再生/ストップ（左右両方に適用）
- ←キー　動画の場合10秒巻き戻ります
- →キー　動画の場合10秒スキップします

また、画像の場合は画面を左ダブルクリックで拡大、右ダブルクリックで初期状態まで縮小できます。

スマホの画面サイズでは画面分割は対応していません。左右ボタンもありませんが、左右スワイプが対応します。ピンチインで縮小、ピンチアウト・ダブルタップで拡大です。
### アップロード
ドラッグ＆ドロップでアップロードすると、参照フォルダ内や同じアップロード内の完全一致ファイルを自動でスキップします。完了表示で保存件数と重複によるスキップ件数を確認できます。ゴミ箱内のファイルはスキップの判定対象になりません。

### 設定
メディア一覧画面では画面右上に歯車マークがあり、押すと設定画面に入れます。

「キーボードショートカット」はキーボードショートカットの確認と再設定、およびデフォルト設定への復元ができます。

「参照フォルダ」は本アプリが参照するフォルダの確認と削除/追加ができます。

「言語」はEnglishまたは日本語へ表示を切り替えます。

「パスワードリセット」はパスワードをリセットします。初期状態に戻り、参照するフォルダもリセットされます。
